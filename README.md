
Aphex is a website made to help CSULB students find food quickly. It gives you the latest info on where and when dining halls, food trucks, vending machines, and convenience stores are open, so you can easily plan your next meal.


✨ What It Does (Features)

Up-to-Date Dining Hall Menus:
See what's being served today in Parkside, Hillside, and Beachside dining halls, including info on allergens (like nuts or dairy).

Food Truck Location Map: 
Find out which food trucks are on campus right now, exactly where they are located, and when they open and close.

Snack & Microwave Finder: 
Quickly locate the nearest vending machine or microwave using a simple map.

See Everything on a Map: 
View all dining spots and food amenities clearly laid out on an interactive campus map.

Night Mode (Dark Mode): 
Switch to a dark screen theme to make viewing easier on your eyes.


🚀 How to Run It (Getting Started)
Follow these steps to get the website running on your own computer.

What You Need (Prerequisites)
Node.js (Version 18 or newer works best)
npm (This tool comes with Node.js)


**Installation Steps**
Get the project files:

git clone https://github.com/fairywispp/aphex.git
cd aphex

Install the necessary tools:
npm install

Start the website:
npm run dev

View the app: 
Your computer's terminal will give you a web address (like http://localhost:8080). 


Project Folders -	What's Inside
src/pages	The main pages you see when you visit the site (Home, Schedule, etc.).
src/components	Small pieces of the website you use over and over (like the search bar or cards).
src/data	The lists and schedules for menus, locations, and food trucks.
src/assets	All the pictures and icons.
